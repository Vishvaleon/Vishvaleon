# About

I'm a B.Tech Artificial Intelligence & Data Science student at SRM Madurai College of Engineering and Technology with interests in Artificial Intelligence, Full Stack Development, Data Analytics, and Geospatial Systems.

My work focuses on building practical software solutions—from AI-powered applications and retrieval systems to scalable web platforms and data-driven tools.

---

# Featured Projects

### 📄 MemoDoc

A full-stack institutional report generation platform deployed across SRM Madurai College, streamlining event documentation and reducing report preparation time from hours to minutes.

**Stack:** React, Django REST Framework, MongoDB Atlas, JWT

---

### 🛰 Smart Satellite Change Detection

A geospatial monitoring system that enables users to track changes within custom Areas of Interest using satellite imagery and spatial analytics.

**Stack:** Vue.js, Django, PostgreSQL, PostGIS, OpenLayers

---

### 🤖 RAG Pipeline

A document intelligence system leveraging semantic search and local large language models to provide context-aware question answering.

**Stack:** LangChain, FAISS, Hugging Face, LM Studio

---

### 📰 Misinformation Detection System

A multi-modal AI solution designed to identify misleading content across text, images, and videos using natural language processing and computer vision techniques.

**Stack:** Python, Transformers, OpenCV, Scikit-Learn
